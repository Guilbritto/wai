# wai "Campo" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One visual language ("Campo") for every control in wai and in extension panels, dark and light, plus a path field that Settings → Shell and extensions (new `path` node, API 1.6) use.

**Architecture:** Colors gpui-component paints itself change in `aurora.json` (dark) and a new "wai Aurora Light" entry. Shapes the theme cannot express live in a new `crates/wai/src/campo.rs` (heights, halo, tinted tones, recessed fields, loose rows, small labels). A new `crates/wai/src/path_field.rs` entity is the path field. Every call site routes through `campo`.

**Tech Stack:** Rust, GPUI via gpui_kit 0.9.0 (gpui-component 0.9.0), wai-ext (panel schema), Go storybook extension.

**Spec:** `docs/superpowers/specs/2026-11-16-wai-campo-design.md`

## Global Constraints

- No patch to gpui-component; only its public hooks (`Styled`, `appearance(false)`, `ButtonCustomVariant`, `Tag::custom`).
- Control height in a row: 28 px; radius 8; disabled opacity .42.
- Recessed `#00000033` (log/code `#00000040`), border `#ffffff1a`; glass `#ffffff0b`, hover `#ffffff17`.
- Focus: border `#8d72ff73` plus 3 px halo `#8d72ff33`. On/chosen: `#36e2c0` with mark `#0b1024`.
- Tones tinted ~15% bg, tone text, alerts and danger get a ~35–40% border.
- `theme.primary == aurora::boreal()` stays true.
- Commits: `feat:`/`fix:`/`chore:`, no scope, no Co-Authored-By. Extension/docs/storybook material is `chore:`.
- CI gates: `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`; storybook `go vet ./... && go test ./...`.

## Review Focus

1. A path typed with `~` reaches the extension expanded; an absolute path outside home is sent untouched.
2. A `path` node re-rendered with the same `value` keeps what the user typed or picked (initial-value rule).
3. Light mode: no dark surface leaks (recessed/glass helpers branch on `is_dark()`).
4. Keyboard focus still visible on every restyled control (focus border/halo, not only hover).
5. A `pick: "folder"` field never offers files in the picker, and `editable: false` never takes typing.

### Task 3: `campo` helpers

**Files:** Create `crates/wai/src/campo.rs` (+ `mod campo;` in `main.rs`/`lib.rs`).

**Produces (all `pub(crate)`):**
- `const H: f32 = 28.`, `const RADIUS: f32 = 8.`
- colors, each `fn(cx: &App) -> Hsla`, branching on `is_dark()`: `recessed`, `glass`, `glass_hover`, `line`, `focus`, `on`, `mark`, `dim`.
- `fn halo(cx: &App) -> Vec<BoxShadow>` (3 px spread, `#8d72ff33` / light `#7b5cf02e`).
- `fn field<E: Styled>(el: E, focused: bool, cx: &App) -> E`: h 28, radius 8, recessed bg, line border, focus border + halo when `focused`.
- `fn tint(tone: Tone, cx: &App) -> (Hsla, Hsla, Hsla)`: (bg ~15%, text, border ~38%); `Neutral` → (glass, muted, line).
- Buttons: `fn button(b: Button, cx: &App) -> Button` (glass, 28, radius 8, 12 px semibold); `fn primary(b, cx)`; `fn danger(b, cx)` (tinted via `aurora::filled` + border); `fn ghost(b)`; `fn icon(b)` (28 square).
- `fn label(text: impl Into<SharedString>, cx: &App) -> Div`: 10.5 px, 700, uppercase, muted.
- `fn loose_row(cx: &App) -> Div`: glass row, radius 9, hover violet (`#8d72ff29`/`#8d72ff73`).
- `fn badge(text, tone, cx) -> Div`: tinted, radius 6, 10.5 px 700.
- [ ] Test `tint_mixes_the_tone`: danger in dark gives bg alpha ≈ .15 and text == `aurora::erro()`.
- [ ] Commit `feat: add the Campo control helpers`.
